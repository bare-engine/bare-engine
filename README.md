Build for Web:
- 34kb minimal game (gzip)
- Fast loading time
- Easy asset streaming
- Ingame level editor
- Object inspection in extension
- Components
- Make your own tools/editor
- Save/load levels
- Fast rendering ([Rapid](https://github.com/Nightre/Rapid.js))
- Fast hot reload (vite)
- Open source
