<h1>Bare Game Engine</h1>

Build for Web:
- 28kb minimal game (gzip)
- Instant load time
- Asset streaming
- Ingame level editor
- Object inspection in plugin
- Components
- Make your own tools/editor
- Save/load levels
- Hot reload (vite)
- Open source
