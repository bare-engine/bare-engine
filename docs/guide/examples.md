# Examples

These projects are linked throughout the docs.

| Project | Shows |
| --- | --- |
| [Template](https://github.com/bare-engine/bare-template) | The starting point for a new game. See [Getting Started](./getting-started). |
| [Showcase](https://github.com/bare-engine/bare-showcase) | A small demo per feature: image loading, animation, render textures, graphics, particles, shaders, tweens, prefabs, components, extending classes, levels, editor components, both physics engines, sound, camera and UI anchoring. |
| [Platformer](https://github.com/bare-engine/bare-platformer) | A small, complete game: player movement and animation, gravity, levels, UI, sound, tweens, collisions and tags, asset streaming, custom events, particles and inspector buttons. Fills the window. |
| [Shmup](https://github.com/bare-engine/bare-shmup) | A shoot 'em up: collision layers, shooting projectiles, custom component methods, and `pixelScale` for chunky pixels. |
| [RPG](https://github.com/bare-engine/bare-rpg) | A pixel art RPG: touch and keyboard movement, levels connected with editor components and its own map editor, enemy AI, hitboxes, saving and loading, level preloading, prefab inheritance and a custom weapon class. Fixed resolution, scaled to fit. |
| [Trust](https://github.com/bare-engine/bare-trust) | A port of *The Evolution of Trust*: prefab buttons, a custom GameObject class, promise-based tweens and a UI scene. |
| [Resolution Demo](https://github.com/bare-engine/bare-resolution-demo) | The [resolution](./resolution) options side by side. |
